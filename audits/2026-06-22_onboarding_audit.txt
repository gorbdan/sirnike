# Аудит онбординга Сырника — взгляд новичка

Дата: 2026-06-22
Скоуп: первый контакт с ботом — `/start`, приветствие новичка, витрина,
`/balance`, `/help`, первая генерация, реферальный вход.
Метод: ревью текущего кода `SirNike.py` (без обращения к LLM-API).

Контекст: это продолжение аудита, начатого в соседней сессии и не доведённого
до конца (последние авто-прогоны в `audits/` падали с «credit balance too low»).
Номера строк сверены с актуальным кодом на ветке.

---

## UX-аналитик Telegram-ботов с фокусом на новичков

Хорошие новости: со времён прошлых аудитов онбординг заметно подтянули —
у новичка есть витрина «такое делают пользователи» с кнопками «хочу так же»
(`SirNike.py:1614`), в ошибке «нет промпта» теперь есть кнопки «Библиотека»
и «Как пользоваться» (`SirNike.py:3506`), а `/balance` показывает время сброса.
Ниже — то, что осталось и реально мешает новичку.

---

### 🟡 [SirNike.py:1595, 1716] Грамматика числа: «3 бесплатная генерация»

**Сценарий:** новичок открывает бота при `FREE_GENERATIONS_PER_DAY` ≠ 1
(в README пример с другими значениями вполне реален).

**Что видит:**
```
• ещё 3 бесплатная генерация каждый день      (приветствие)
🆓 3 бесплатная генерация каждый день          (/help)
```

**Проблема:** склонение захардкожено в единственном числе. Любое значение,
кроме 1, даёт грамматически неверный текст на самом первом экране — это бьёт
по доверию ровно там, где оно важнее всего.

**Фикс:** склонять по числу. В коде уже есть стиль `photos_label` (см.
`SirNike.py:1909`) — переиспользовать тот же helper, например:
```python
free_word = pluralize(FREE_GENERATIONS_PER_DAY, "бесплатная генерация",
                      "бесплатные генерации", "бесплатных генераций")
```

### 🟡 [SirNike.py:1664–1673] `/balance`: противоречие про время сброса

**Сценарий:** новичок исчерпал бесплатные и проверяет баланс поздно вечером
(например, в 23:40 МСК).

**Что видит:**
```
Бесплатных генераций: ❌ исчерпаны (новые через ~0ч 20мин)
Следующий сброс: завтра в 0:00 по московскому времени
```

**Проблема:** две строки противоречат друг другу. `free_status` считает реальный
остаток до полуночи (`~0ч 20мин`), а строка ниже статично говорит «завтра» —
хотя сброс наступит сегодня же ночью, через 20 минут. Новичок не понимает,
ждать ему 20 минут или до завтра.

**Фикс:** убрать дублирующую статичную строку «Следующий сброс: завтра…» —
динамический `free_status` уже несёт эту информацию и точнее. Либо привести
обе строки к одному источнику (`_next_reset`).

---

### 🟡 [SirNike.py:1614–1650] Витрина новичка: одна битая ссылка рушит весь экран

**Сценарий:** у новичка первый `/start`; одна из картинок витрины недоступна
(истёк CDN-URL примера из библиотеки).

**Проблема:** альбом шлётся одним `reply_media_group(media)` — операция
атомарна, поэтому один недоступный `example_url` роняет ВЕСЬ альбом в `except`.
А блок `except` лишь пишет в лог и не отправляет ничего — даже текстового
фоллбэка с кнопками «хочу так же». В итоге у части новичков самый сильный
конверсионный экран просто молча исчезает.

**Фикс:** (1) валидировать/собирать `media` отказоустойчиво — пропускать битые
элементы, а не падать всем альбомом; (2) в `except` всё равно показать
текстовые кнопки витрины (callbacks `shc_*` уже самодостаточны и не зависят
от медиа).

### 🟢 [SirNike.py:1594] «Изюминки» не расшифрованы при первом контакте

**Сценарий:** человек впервые видит приветствие.

**Что видит:**
```
• подарок на старте — 250 изюминок (250 фото)
```

**Проблема:** привязка «изюминки → фото» есть (это уже хорошо), но само слово
«изюминки» нигде не названо валютой. Новичок может не понять, почему фото-бот
оперирует «изюминками».

**Фикс:** добавить одно уточнение при первом упоминании, например:
`«изюминки — внутренняя валюта бота, 1 фото = N изюминок»`.

---

### 🟢 [SirNike.py:967–983] `/help` не достаётся кнопкой из главного меню

**Сценарий:** новичок закрыл приветствие, листает меню и хочет понять, как всё
работает.

**Проблема:** `main_menu_kb()` не содержит кнопки «Как пользоваться». Справка
есть только командой `/help` (которую надо вспомнить/напечатать) и через
callback `show_help` в одном частном сценарии (ошибка «нет промпта»). Точка
входа в помощь — неравномерная.

**Фикс:** добавить в меню кнопку `❓ Как пользоваться` (callback `show_help`),
рядом со «Сообщить о проблеме».

---

### 🟢 [SirNike.py:1555–1579] Реф-бонус молча игнорируется для «не новых»

**Сценарий:** человек уже писал боту раньше, потом перешёл по реф-ссылке друга.

**Проблема:** бонус начисляется только при `is_new_user and mark_referral_bonus`.
Если пользователь не новый — переход обрабатывается молча: ни бонуса, ни
объяснения. Пригласивший тоже ничего не получает и не понимает почему.
Это не баг логики (защита от абуза верная), но точка тихого разочарования.

**Фикс:** при переходе по ref-ссылке существующего пользователя показать мягкое
пояснение: «Бонус за приглашение начисляется только новым пользователям».

---

### 🟢 [SirNike.py:3898–3903] Фоллбэк библиотеки звучит как поломка

**Сценарий:** `PROMPT_WEBAPP_URL` не задан; новичок жмёт «Библиотека стилей 📚».

**Что видит:**
```
WebApp пока не подключен. Используй встроенную библиотеку ниже.
```

**Проблема:** функционально всё ок (показывается встроенная библиотека), но
формулировка «пока не подключен» читается новичком как «что-то сломалось».

**Фикс:** нейтральная формулировка без «не подключен», например:
`«Выбери стиль из библиотеки 👇»` — встроенная библиотека и так полноценна.
