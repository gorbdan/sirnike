## Статус

- [x] Отобраны топ-20 стилей из `prompt_library.json` (все категории кроме «Парные»/«Дети» —
      выпали 3 самых нишевых, чтобы уложиться в 20 и сохранить разброс по темам).

      уже готовый результат из библиотеки).
- [ ] BEFORE-селфи — ждём от Ани (положить в папку `before/`, имя файла = номер строки
      из `top20_styles.md`, например `before/03.jpg`).

## Файлы

- `top20_styles.md` — таблица «# / категория / стиль / AFTER-пример» для чтения.
- `top20_styles.json` — то же в машиночитаемом виде (пригодится, если селфи будут
  прогоняться через генерацию по промптам стилей).
- `before/` — сюда кладутся присланные селфи.

## Как закончить, когда придут селфи

1. Разложить селфи в `before/` по номерам из таблицы (или сказать, какое селфи к какому
   стилю подходит по типу образа — глянец/деловой/пляж и т.д.).
2. Либо прогнать через генерацию по `prompt` из `top20_styles.json` (если нужен новый
   AFTER под конкретное селфи), либо использовать готовый `example_url` как есть.
3. Отметить бриф `[x]` в [docs/briefs/content.md](../../docs/briefs/content.md) с путём
   `audits/before_after_2026-07-02/`.
