# UI-гайд Сырника: единый язык кнопок и экранов

Владелец гайда — фронтенд ([roles/frontend.md](roles/frontend.md)). Любая новая
кнопка или экран в боте и вебаппе обязаны следовать этим правилам. Меняешь
правило — меняй ВСЕ кнопки под него в том же PR.

## Эмодзи-язык (один смысл = один эмодзи)

| Эмодзи | Смысл | Примеры |
|---|---|---|
| 🚀 | запуск генерации, когда всё готово | «🚀 Запустить генерацию», «🚀 Запустить видео» |
| ✨ | продукт «фото» и применение стиля | «✨ Сгенерировать фото», «✨ Использовать этот стиль» |
| 🎬 | всё про видео | «🎬 Видео для Reels», «🎬 Использовать в видео» |
| 🪄 | аватар | «🪄 Аватар» |
| 🖼️ | улучшение фото | «🖼️ Улучшить фото» |
| 📚 | библиотека стилей | «📚 Библиотека стилей», «📚 Выбрать стиль» |
| 💰 / 💳 | баланс / покупка | «💰 Баланс», «💳 Купить изюминки» |
| 🍇 | изюминки в КНОПКАХ (компактно) | «10с · 70 🍇» |
| 🎁 | реферальная программа | «🎁 Пригласить друга» |
| ◀️ | назад/в меню — ЕДИНСТВЕННАЯ стрелка навигации | «◀️ В меню», «◀️ Назад», «◀️ К категориям» |
| ✖️ | отмена/закрыть (НЕ ❌) | «✖️ Отмена», «✖️ Закрыть» |
| ✅ | статус «шаг выполнен» (не CTA!) | «✅ Описание добавлено» |
| ● | выбранный вариант в переключателях | «● Seedance 2» |
| 🆕 | новинка | «Kling 3.0 🆕» |
| 🧹 | очистить/сбросить накопленное | «🧹 Очистить все фото» |
| ❓ / 🚨 | помощь / проблема | «❓ Как пользоваться», «🚨 Проблема» |

## Правила кнопок

1. **Один эмодзи на кнопку, всегда в начале.** Исключения: ● и цифры-шаги
   (1️⃣ 2️⃣) стоят первыми как маркер состояния; 🆕 и 🍇 — в конце как бейдж/валюта.
2. **Цена в кнопке** — всегда «N 🍇», в текстах сообщений — словами («70 изюминок»).
3. **Тексты кнопок и упоминания в инструкциях совпадают буква в букву**,
   включая эмодзи и его позицию (частый источник багов — см. audits/).
4. **Порядок рядов**: контент/шаги → настройки → главный CTA → навигация.
   «◀️ В меню» — всегда последний ряд, один в ряду.
5. **Ширина**: главный CTA, «◀️ В меню» и «📚 Библиотека стилей» (витрина) — на всю
   ширину; остальные короткие кнопки — парами/тройками в ряд. Условные кнопки
   (появляются по фиче-флагу) — одни в ряду, чтобы сетка не дёргалась.
   Главное инлайн-меню зеркалит сетку reply-клавиатуры — у юзера одна карта кнопок.
6. **Формулировки**: глагол в начале («Запустить», «Выбрать», «Купить»),
   без техножаргона, обращение на «ты». ЦА — девушки 18–35 с телефона.
7. **Названия одного и того же места одинаковы везде**: раздел зовётся
   «📚 Библиотека стилей» и в инлайн-меню, и в reply-клавиатуре, и в текстах.

## Словарь CTA (не плодить синонимы)

| Ситуация | Кнопка |
|---|---|
| всё готово к запуску фото | «🚀 Запустить генерацию» |
| всё готово к запуску видео | «🚀 Запустить видео» |
| можно генерить, но можно и дополнить | «✨ Сгенерировать фото» |
| стиля ещё нет | «📚 Выбрать стиль» |
| стиль уже применён | «📚 Выбрать другой стиль» |
| применить стиль из карточки | «✨ Использовать этот стиль» / «🎬 Использовать в видео» |
| повторить то же самое | «🔁 Повторить» |

## Экраны

- Первая строка сообщения = заголовок экрана с эмодзи раздела («💰 Твой баланс»).
- Статусы черновика — компактным списком «Ключ: значение», без пустых строк между ними.
- Тире — длинное «—», кавычки — «ёлочки», числа от слов отбиваются пробелом.
- Один экран = одно сообщение; не слать вдогонку второе, если можно одним.
