## 1. Seedance 2.5 (ByteDance) — приоритет №1, есть дедлайн

**TL;DR:** вышла 31.07.2026, у нас сейчас 2.0. Дороже текущей модели при
одинаковом качестве, НО даёт нативные 30-секундные ролики без склейки клипов
(закрывает пункт роадмапа «нейромультик»). Рекомендация — премиум-тариф по
образцу GPT-5 Image, не тихая замена Seedance 2.0. **Нужен live-тест** —
цифры ниже из публичных прайсов, не из реального счёта.

### Что нового у 2.5 vs 2.0
- Нативный проход до **30 секунд** одним вызовом (у 2.0 через Zveno — жёсткий
  потолок 15 сек у любого провайдера, см. AGENT_NOTES.md 2026-07-08).
- До 50 референсов (фото/видео/аудио) вместо текущих 9 (`MAX_SEEDANCE_IMAGE_REFERENCES`).
- Режимы: text-to-video, image-to-video, reference-to-video.
- Модели API (EvoLink): `seedance-2.5-text-to-video`, `seedance-2.5-image-to-video`,
  `seedance-2.5-reference-to-video`.

### Экономика (публичные прайсы, курс ориентир ~90 ₽/$)

| Провайдер | Режим | Цена | ₽/сек | Источник |
|---|---|---|---|---|
| **Сейчас: Zveno, Seedance 2.0** | обычный | 12.10→ фактически 11.38 ₽/сек (закупка) | 11.38 | config.py:189 (комментарий у Kling3, тот же ориентир), docs/specs/2026-07-31_evolink_video_provider.md |
| Сейчас: Zveno, Seedance 2.0-fast | — | ~9.1 ₽/сек (оценка) | ~9.1 | там же |
| EvoLink, Seedance 2.5, 720p standard | text/image-to-video | $0.293/сек | **26.37** | evolink.ai/seedance-2-5 |
| EvoLink, Seedance 2.5, 720p reference | video-reference/edit/extend | $0.179/сек | **16.11** | evolink.ai/seedance-2-5 |
| EvoLink, Seedance 2.5, 480p standard | text/image-to-video | $0.136/сек | 12.24 | evolink.ai/seedance-2-5 |
| EvoLink, Seedance 2.5, 480p reference | video-reference/edit/extend | $0.083/сек | 7.47 | evolink.ai/seedance-2-5 |
| fal.ai, Seedance 2.5, 720p | тот же playground, что у нашей 2.0 | $0.4730/сек | 42.57 | fal.ai/models/bytedance/seedance-2.5 |
| fal.ai, Seedance 2.5, 480p | — | $0.2205/сек | 19.85 | fal.ai/models/bytedance/seedance-2.5 |

**Важная неопределённость**: EvoLink делит биллинг на «standard» и
«video reference/edit/extend» и пишет, что режим reference «may be billed by
input + output duration». Наш прод использует фото-референсы персонажа
(`SEEDANCE_VIDEO_REFERENCE_MODE=character`, `input_references`) — неясно,
попадают ли фото-референсы (не видео) под дешёвый reference-тариф или под
дорогой standard. Это решает только реальный вызов API — не додумываю.

### Нужный тариф в изюминках при целевой марже x3.3 (5 ₽/изюминка)

| Сценарий | Закупка ₽/сек | Тариф, изюм/сек | Δ к текущим 6.75 |
|---|---|---|---|
| 720p standard (EvoLink) | 26.37 | ~17.4 → **17-18** | +160% |
| 720p reference (EvoLink) | 16.11 | ~10.6 → **11** | +63% |
| 480p standard (EvoLink) | 12.24 | ~8.1 → **8** | +19% |
| 480p reference (EvoLink) | 7.47 | ~4.9 → **5** | **дешевле текущего** |

Если фото-референс на 2.5 попадёт под дешёвый reference-тариф — 480p версия
выходит даже дешевле сегодняшней Seedance 2.0, а 720p reference — приемлемый
премиум (+63%, сопоставимо с наценкой GPT-5 Image против Nano Banana). Если
попадёт под дорогой standard — экономика не бьётся без отдельного премиум-тарифа.

### Рекомендация
1. **Не переключать Seedance по умолчанию на 2.5** — ждать live-теста.
2. Тест-план (нужен ключ EvoLink от Ани — см. открытый пункт):
   `POST /v1/videos`, модель `bytedance/seedance-2.5-reference-to-video`,
   720p, 1-2 фото-референса (как в character-режиме), 5-10 сек — сверить,
   под какой биллинг-режим попадает счёт, и визуально сравнить качество с
   текущей 2.0 (тот же чек-лист, что для EvoLink-миграции 2.0, см. спеку).
3. Если экономика подтвердится в разумных рамках (±30% от таблицы) —
   позиционировать как **отдельный премиум-продукт** «Видео 2.5 / нейромультик»
   с ценой 11-18 изюм/сек и акцентом на 30-секундный ролик без склейки —
   бриф backend на реализацию, не тихая подмена модели по умолчанию.
4. Срок для креатора — тест хочет за неделю. Учитывая, что реальный
   API-вызов заблокирован ключом EvoLink, первый шаг — Аня выдаёт ключ.

## 3. Midjourney — персонализация / mood-борды / вкладка стилей

**TL;DR:** у самой Midjourney **нет публичного API** — доразведала рынок
сторонних провайдеров (PiAPI, GoAPI, useapi.net, LegNext.ai) специально по
запросу: они дают доступ к генерации, но НЕ к персонализации/mood-бордам, и
несут риск бана аккаунта. Вывод не поменялся: интегрировать нечего, для
соответствия ожиданиям креатора нужен свой аналог функции, не подключение
провайдера.

### Что именно она хвалит (по фичам Midjourney)
1. **Персонализация** — юзер обучает «свой стиль» на своих же оценённых/
   загруженных картинках, дальше он подмешивается ко всем промтам.
2. **Mood-борды** — коллекции референс-картинок (как Pinterest-борд),
   несколько профилей сразу, каждый борд — свой стилевой профиль.
3. **Вкладка со стилями** — отдельный раздел интерфейса для просмотра/выбора
   стиля до генерации.

### Что у нас есть уже / чего нет
- «Вкладка со стилями» — по сути уже есть: библиотека стилей в вебаппе
  (docs/BOT_CONTRACT.md). Разница в глубине персонализации, не в наличии раздела.
  → сверить у прод-версии, приоритизировать не мне (зона фронтенда/UX).
- «Персонализация» и «mood-борды» (свой обучаемый профиль вкуса из
  референс-картинок пользователя) — этого нет. Это UX/продуктовое решение
  (структура экрана, что показываем, как обучаем профиль), не разведка рынка.

### Через сторонних провайдеров — доразведка (по запросу)

Проверила рынок «Midjourney API»-ресейлеров, которые автоматизируют Discord/веб
под капотом (сама Midjourney официального публичного API не даёт):

| Провайдер | Статус на 2026-08-08 | Цена | Персонализация/mood-борды |
|---|---|---|---|
| PiAPI | сервис Midjourney **закрыт**, редиректит на LegNext.ai | было: relax $0.015/generate, fast $0.045, turbo $0.10, либо $8/мес BYOA | не упоминается в доках — только `--sref`/`--cref` |
| GoAPI | сервис Midjourney **закрыт**, редиректит на LegNext.ai | было: $8/мес Developer Plan | Персонализация/mood-борды упоминаются в их доках как параметры промта, но сервис уже не работает |
| useapi.net | Midjourney-поддержка **прекращена 24.06.2026** | было: $10/мес flat | не документирована отдельным эндпоинтом |
| LegNext.ai | заявлен как текущий выживший игрок | не проверила — сайт отдаёт 403 на автоматический запрос, нужен ручной заход | не проверила |

**Почему это не «просто ещё один провайдер»:**
1. **Три из четырёх найденных сервисов уже закрыли Midjourney-интеграцию в 2026** —
   рынок ресейлеров сжимается, это не стабильная инфраструктура для платного
   прод-продукта.
2. Все они работают в обход правил самой Midjourney (автоматизация Discord/
   веб-бота прямо запрещена ToS) — риск бана аккаунта в любой момент, сервис
   может отвалиться без предупреждения (что и произошло у трёх из четырёх).
3. Даже там, где генерация доступна, **персонализация и mood-борды нигде не
   заявлены как поддерживаемый параметр API** — только `--sref`/`--cref`
   (стилевой референс по картинке, не обучаемый профиль). Технически `--p
   <код>` тоже просто текст в промте и мог бы пройти, но сам профиль/борд
   всё равно создаётся только вручную на midjourney.com — автоматизировать
   создание нечем, только использование уже готового чужого кода.

**Вывод не меняется**: даже если закрыть глаза на ToS-риск, ни один найденный
провайдер не даёт того, что хвалит креатор (создание своей персонализации/
mood-борда программно) — это функции исключительно веб-интерфейса Midjourney.
Рекомендация остаётся прежней — свой аналог, не интеграция.

**Передаю находку по адресу**: это бриф для ux-ui-designer (спека экрана) +
маркетолога (стоит ли в принципе, приоритет в воронке) — не оформляю сама
бриф backend, т.к. решение «делать/не делать» вне моего мандата.

Источники: [Midjourney Moodboards docs](https://docs.midjourney.com/hc/en-us/articles/39193335040013-Moodboards),
[Midjourney Personalization docs](https://docs.midjourney.com/hc/en-us/articles/32433330574221-Personalization),
[PiAPI Midjourney API](https://piapi.ai/midjourney-api) (сервис закрыт),
[GoAPI Midjourney API](https://goapi.ai/midjourney-api) (сервис закрыт),
[useapi.net Midjourney API v2](https://useapi.net/docs/api-v2) (поддержка прекращена 24.06.2026).
