# Брифы: контент

Формат: бриф = формат + оффер + хук + куда результат. Выполнил — ставь `[x]` и путь к материалам.

## Очередь

- [ ] P0 · Библиотека примеров: 20 сильных before/after (селфи → результат) по топ-стилям
      библиотеки. Результат: папка с парами картинок + строка «стиль → пример» списком.
      Это сырьё для всего остального контента и закрепа.
- [ ] P1 · 10 постов для Telegram-канала по рубрикам из MARKETING_PLAN.md («Образ дня»,
      «Из селфи в обложку», «Промпт недели», «3 идеи для аватара»…). Оффер в каждом:
      «1 генерация бесплатно каждый день». Ссылка с меткой: `?start=s_tgchannel`.
- [ ] P1 · 3 рилса before/after (хук по правилу из памяти: число в хуке = столько показать).
      Форматы: beauty-глянец / деловой аватар / пары. Метка: `?start=s_reels`.
- [ ] P2 · 2 варианта текста рассылки в боте под новую коллекцию стилей (короткие,
      1 визуальный пример, 1 кнопка) — на согласование маркетологу.
