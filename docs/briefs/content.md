# Брифы: контент

Формат: бриф = формат + оффер + хук + куда результат. Выполнил — ставь `[x]` и путь к материалам.

⚠️ **Инсайт 2026-07-04 (данные с аккаунта Ани):** до/после НЕ залетает как рилс —
алгоритм его не крутит. Залетают Seedance-видео (зрелищные AI-видео, «эмпайр»-формат),
причём на мужскую аудиторию. Раздели поверхности:
- **Рилсы = только Seedance-формат** (охват). Продукт вшивать в конец + пин-коммент.
- **До/после = пруф**, не охват: посты канала, посевы, карточки вебаппа. Там оставить.
- Оффер везде «первое фото бесплатно» (бесплатных ежедневных генераций НЕТ).
