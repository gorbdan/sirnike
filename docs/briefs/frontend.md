## Очередь

- [ ] P0 · Payload «Использовать» теряет/путает стиль — 2 причины, полное ТЗ:
      [docs/specs/2026-07-12_webapp_payload.md](../specs/2026-07-12_webapp_payload.md).
      Кратко: (1) поиск/фильтр шлёт `cat_idx`/`item_idx` относительно
      отфильтрованного списка вместо полного `prompt_library.json` — юзер
      выбирает «Полароид: детское фото», бот отвечает «Портреты» с чужой
      подсказкой (audits/2026-07-07_live_ux_audit.txt, №3); (2) длинный `prompt`
      режется посередине при превышении лимита payload вместо того, чтобы
      убрать поле целиком и слать только индексы, как требует контракт —
      из-за этого подсказка «Что загрузить» терялась именно у длинных стилей
      (подтверждено живьём 2026-07-12). Бот с обеих сторон защищается
      костылями (сравнение по префиксу вместо полного, игнор чужих индексов),
      но нужно чинить источник. Критерий и рекомендация (не слать `prompt`/
      `title` вовсе, если есть валидные индексы) — в ТЗ выше.
- [ ] P1 · 1-клик до библиотеки с ИНЛАЙН-кнопок бота: поддержать
      `answerWebAppQuery` (вебапп получает query_id в initData → шлёт выбор через
      Telegram.WebApp API, а не sendData). Контекст: sendData работает только с
      reply-клавиатуры; попытка повесить web_app на инлайн-кнопки в боте молча
      ломала «Использовать» (audits/2026-07-07_live_ux_audit.txt, №1) и откачена.
      Критерий: «Использовать» доставляет выбор боту из вебаппа, открытого с
      инлайн-кнопки. Согласовать формат с бэкендом (нужен хэндлер в боте).
- [ ] P1 · Перед «Использовать» показывать «что загрузить» как обязательный шаг,
      если у стиля есть `upload_hint` (например, «Фото сейчас + детское фото»).
      Критерий: юзер не может применить стиль, не увидев требования к фото.
- [ ] P1 · Брендовые примеры вместо внешних заглушек (unsplash) в карточках
      (пункт P3 маркетинг-плана). Источник примеров: библиотека before/after
      от контент-продюсера (docs/briefs/content.md, задача P0).
- [ ] P2 · Раздел «Топ-стили» на главном экране каталога (по статистике использования
      шаблонов из бота — данные спросить у бэкенда).
