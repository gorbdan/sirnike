      - midjourney: `{description, refs}` (0 или 1 элемент)

      - photo: `{description, refs, image_model}`

      `VIDEO_CONSTRUCTOR_ENABLED=1`) шлёт ОДНО сообщение с кнопкой
      «🎬 Открыть конструктор» вместо прежней двухсообщенческой чат-панели —
      URL уже несёт `prefill.description` = промт стиля. Тесты-спецификация:
      `tests/test_block_24_webapp_generation_hub.py`, блоки 24u (роундтрип
      prefill по всем 4 продуктам), 24v/24w (библиотечный редирект,
      вкл/выкл). На стороне вебаппа нужно: при открытии с `prefill` в URL —
      декодировать base64 JSON и заполнить соответствующие инпуты экрана
      теми же ключами, что уже парсятся при сборке исходящего payload (без
      нового формата).
