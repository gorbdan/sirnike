- [x] P1 · Карточка стиля не прокручивалась — кнопки «Копировать»/«Использовать»
      уезжали за нижний край на стилях с полем «свои пожелания» (Бьюти) или
      длинным описанием. — 2026-07-16, PR https://github.com/gorbdan/_webapp/pull/14
      (`fix/modal-scroll`). Причина: `.modal-body` — flex-колонка с `max-height`
      без `overflow-y`, родитель `.modal-shell` (`overflow:hidden`) обрезал
      контент выше лимита без скролла. Фикс: `overflow-y: auto`. Воспроизведено
      и проверено на мобильном 375×667 (iPhone SE) реальным скроллом — оба
      стиля категории Бьюти переполняли карточку (scrollHeight 420 > clientHeight
      387), после фикса кнопки полностью доступны. Багрепорт со скриншотом
      Telegram Desktop от Ани.
