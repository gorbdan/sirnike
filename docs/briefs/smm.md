# Брифы: СММ Telegram-канала

Формат: `- [ ] P0/P1/P2 · задача · критерий готовности`. Результаты — в docs/marketing/tg-channel/.

## Очередь

- [ ] P0 · Комментинг-плейбук (проверенный канал №1: лучшая конверсия В ПОКУПКУ
      по опыту Ани — комменты под чужими вирусными AI-видосами «у меня в боте можно
      сделать такое, только дешевле»; конкуренты продают такие видео по ~5000 ₽,
      в Сырнике на порядок дешевле). Задача: ежедневный шорт-лист 5–10 свежих
      залетающих AI-видео (рилсы/ТГ; /smm-тренд-парсинг в помощь) + под каждый —
      готовый живой коммент (humanizer-ru, personal). Комментит АНЯ с личного
      аккаунта, вручную — НЕ автоматизировать постинг комментов, это бан и спам.
      Трафик идёт через профиль → шапку (метка s_inst) — не менять её без учёта этого.
      Критерий: Аня утром открывает список и тратит 15 минут на комменты.

- [ ] P0 · Статус канала: если канала нет — чек-лист запуска Ане (название,
      описание со ссылкой `s_tgchannel`, аватар, закреп); если есть — аудит
      текущего состояния. Критерий: канал готов принимать контент-план.
- [ ] P0 · Контент-план на 2 недели: 1–2 поста в день по рубрикам
      MARKETING_PLAN §6 («Образ дня», «Из селфи в обложку», «Новые стили»,
      до/после и т.д.), под каждый пост — источник сырья. На утверждение Ане.
- [ ] P0 · Закреп-пост: что умеет бот (4 продукта), 2–3 сильных примера,
      честный оффер, ссылка `?start=s_tgpin`. Через humanizer-ru.
- [ ] P1 · Тексты первых 10 постов из контент-плана — пачкой, через
      humanizer-ru, каждая ссылка с меткой. Критерий: Аня может публиковать
      неделю не написав ни строчки.
- [ ] P1 · Разобраться с пайплайном /smm (n8n): что настроено, чего не хватает
      для полуавтомата «пост по расписанию после ок Ани». Автопостинг без
      подтверждения — НЕ включать.
- [ ] P2 · Механика «пост ↔ рассылка в боте»: раз в неделю пост о новых стилях
      дублируется рассылкой (тексты готовит СММ, запускает Аня).
