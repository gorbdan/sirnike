## 1. Создать канал

- [ ] Тип: публичный канал (нужна публичная ссылка для посевов и шапки бота).
- [ ] **Название** — выбрать один вариант (или свой):
  1. **Сырник | AI-фото и видео** — по делу, ищется по слову «сырник».
  2. **Сырник: из селфи в обложку** — сразу главное обещание.
  3. **Сырник. Фото без фотосессии** — боль аудитории в названии.

  Рекомендация — вариант 1: нейтральный к рубрикам (влезут и стили, и видео,
  и до/после), не устареет при смене оффера.
- [ ] **Публичная ссылка (username)**: `sirnike` / `sirnike_ai` / `sirnike_bot_news` —
  что свободно. Короче — лучше: юзернейм попадёт в посевы и в описание бота.

## 2. Описание канала

Лимит Telegram — 255 знаков. Ссылка обязательно с меткой `s_tgchannel`
(переходы смотрим в /audience_stats). Готовый текст (233 знака):

> Обычное селфи превращаю в глянцевый портрет, деловой аватар или видео для
> Reels. Промты писать не надо - стили уже готовы, лицо остаётся твоим.
> Показываю до/после и новые стили.
>
> Первое фото - бесплатно: https://t.me/SirNikeBot?start=s_tgchannel

⚠️ Оффер только «первое фото бесплатно» (стартовый бонус). Никаких «бесплатно
каждый день» и «бесплатное видео» — этих механик нет.

## 3. Аватар канала

- [ ] Квадрат ≥ 640×640, читаемый в кружке 40px (проверить на телефоне).
- [ ] Вариант без дизайнера на сегодня: самый сильный «после»-портрет из
      библиотеки примеров контент-продюсера (его P0-задача в
      docs/briefs/content.md; в репо готовых пар пока нет — спросить напрямую).
      Критерий: яркое лицо крупным планом, без текста.
- [ ] Постоянный вариант — заказать у дизайнера (бриф в docs/briefs/design.md
      напишет маркетолог): узнаваемый знак «Сырника», единый с аватаром бота.

## 4. Настройки канала

- [ ] Включить **комментарии** (привязать группу-обсуждение) — вовлечение
      и соцдоказательство, зона СММ по роли.
- [ ] Включить **реакции** (стандартный набор).
- [ ] Подпись автора у постов — выключить (постим от имени канала).

## 5. Закреп

- [ ] Текст закрепа — отдельная P0-задача СММ (следующая после контент-плана),
      сдам на утверждение отдельно. Состав по брифу: 4 продукта
      («✨ Сгенерировать фото», «🎬 Видео для Reels», «🖼️ Улучшить фото»,
      «🪄 Аватар»), 2-3 сильных before/after, оффер «первое фото бесплатно»,
      ссылка `https://t.me/SirNikeBot?start=s_tgpin`.
- [ ] После публикации — закрепить и не перекреплять без замены.

## 6. Связка бот → канал

- [ ] Добавить ссылку на канал в описание бота (@SirNikeBot, поле «О боте» /
      description в BotFather) — бесплатный обратный поток из бота в канал.
- [ ] Позже (бриф бэкенду от маркетолога, не блокер запуска): пункт/строка
      «наш канал» внутри бота — в /help или под результатом генерации.

## 7. Метки этого запуска (реестр)

| Поверхность | Метка | Ссылка |
|---|---|---|
| Описание канала и посты | `s_tgchannel` | `https://t.me/SirNikeBot?start=s_tgchannel` |
| Закреп-пост | `s_tgpin` | `https://t.me/SirNikeBot?start=s_tgpin` |

Новая поверхность → новая метка, записывать сюда. Двум поверхностям одну метку
не давать. Эффект — в /audience_stats через 48 ч.
