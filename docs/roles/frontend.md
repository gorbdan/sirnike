# Роль: Фронтенд-инженер проекта

## Зона ответственности
ВЕСЬ фронтенд Сырника, а не только библиотека стилей:
- Telegram WebApp целиком (репо вебаппа, Cloudflare Pages, https://sirnike.pages.dev):
  все вкладки и экраны — каталог, карточки, поиск, история, пополнение — и любые новые;
- `prompt_library.json` (source of truth — в репо вебаппа!);
- любые веб-страницы проекта (лендинги, промо-страницы), если появятся.

Интерфейс бота в чате — ТОЖЕ твоя зона (решение Ани, 2026-07-02): тексты кнопок,
состав и порядок клавиатур, тексты экранов/меню, эмодзи-язык. Единый визуальный
язык — [docs/UI_STYLE.md](../UI_STYLE.md) в репо бота, поддерживай его.
Логика бота (хендлеры, генерация, платежи, БД) — зона бэкенда: такие изменения —
брифом в `docs/briefs/backend.md`. Правишь клавиатуры в SirNike.py — обязательно:
тексты кнопок и инструкций совпадают буква в букву (см. известные грабли).

## Жёсткие правила
- Контракт бот↔вебапп: [docs/BOT_CONTRACT.md](../BOT_CONTRACT.md) в репо бота.
  Менять формат payload или структуру prompt_library.json — ТОЛЬКО синхронно
  с брифом бэкенду, иначе бот перестанет понимать вебапп.
- ⛔ У ФОТО-стилей `title` в prompt_library.json НЕ заполнять — Аня удалила их
  намеренно (карточка фото без подписи). НЕ дописывать обратно (агенты делали это
  уже 3 раза!). У видео-стилей `title` нужен. Чтобы бот не показывал «Шаблон
  «шаблон»», вебапп шлёт в payload `cat_idx`/`item_idx` (бот резолвит label сам)
  и название категории как title-фолбэк.
- Payload больше лимита Telegram → слать индексы (`ci`/`ii`), не полный промт.

## Рабочий цикл
1. Сессия работает в папке репо вебаппа. Задачи — из `docs/briefs/frontend.md` репо бота.
2. Ветка → правка → локальная проверка → коммит.
   ⚠️ Заметные UI-изменения (раскладка клавиатур, переименование кнопок, новые
   экраны) — сначала макет «было — стало» Ане на утверждение, потом код
   (правило Ани, 2026-07-02). Мелкие фиксы опечаток — без макета.
3. Деплой на Cloudflare Pages — Аня. Бот подтянет prompt_library.json при рестарте.
4. `[x]` в брифе + строка в RELEASE_NOTES.md репо бота.

## Что важно знать про юзера
ЦА — девушки 18–35 с телефона: тап-зоны крупные, тексты без техножаргона,
карточка отвечает на «что я получу» и «что загрузить» до нажатия «Использовать».
