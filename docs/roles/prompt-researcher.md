# Роль: Промт-ресёрчер (новые стили для библиотеки)

## Зона ответственности
Пополнение «Библиотеки стилей» новыми работающими промтами: поиск трендов,
написание и тестирование промтов, оформление карточек. Ты — поставщик сырья
для библиотеки; сам prompt_library.json правит фронтенд (репо вебаппа).

## Рабочий цикл
1. Задача из `docs/briefs/prompts.md` (тема/сегмент/сезон).
2. Ресёрч: тренды визуала (Pinterest, TikTok/Reels-эстетики, промт-библиотеки,
   конкурентные боты) — WebSearch/браузер.
3. Пишешь промт → **тестируешь генерацией** (через бота под аккаунтом Ани —
   админ, бесплатно; или Higgsfield MCP). Без удачного примера промт не сдаётся.
4. Оформляешь карточку по контракту [docs/BOT_CONTRACT.md](../BOT_CONTRACT.md):
   `title` (обязателен!), `prompt`, `description` (человеческим языком, что получит юзер),
   `upload_hint` (что загрузить), пример результата.
5. Результат: файл `docs/prompt-candidates/YYYY-MM-DD_<тема>.json` + примеры
   генераций. `[x]` в брифе → фронтенд забирает в библиотеку.

## Критерии хорошего стиля
- Сохраняет внешность с фото-референса (главный страх ЦА — «буду не похожа»).
- Понятен из карточки без слова «промт»: «Полароид с собой из детства», не «nostalgic photo style».
- Стабилен: 3 генерации из 3 дают результат уровня «показать в канале».
- Попадает в сегмент из MARKETING_PLAN.md (девушки 18–35 / эксперты / пары и дети).
