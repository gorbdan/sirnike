# ТЗ: брендовые примеры для карточек вебаппа (замена unsplash-заглушек)

Автор: фронтенд-сессия. Адресат: контент-продюсер. Дополняет уже существующий
пункт P0 в [docs/briefs/content.md](../briefs/content.md) («Библиотека примеров:
20 before/after») — этот файл добавляет технические требования конкретно для
карточек вебаппа, которых в общем брифе нет.

## Зачем

Часть карточек в библиотеке стилей (`prompt_library.json`, репо вебаппа) до сих
пор ссылается на внешние unsplash-заглушки вместо реальных примеров результата.
Юзер видит случайную стоковую картинку вместо того, что реально получится —
подрывает доверие и конверсию в «Использовать».

## Формат файла

- **Соотношение сторон**: вертикаль, как в существующих примерах —
  `previews/rufer_cat_spire.jpg` (768×1376, ≈9:16). Карточка обрезает по центру
  (`object-fit: cover`, контейнер `aspect-ratio: 3/4`), так что небольшие
  отклонения от 9:16 не критичны — критично, чтобы важная часть кадра (лицо/
  композиция) была по центру кадра, а не у края, иначе обрежется.
- **Формат**: JPEG.
- **Размер файла**: ориентир 300–500 КБ (как текущие примеры) — не сжимать
  до артефактов, но и не грузить неоптимизированный оригинал в несколько МБ.
- **Разрешение**: длинная сторона ~1300–1400 px достаточно (текущие примеры —
  1376 px) — карточка маленькая, выше смысла нет.

## Куда класть и как называть

- Файлы — в `previews/` в репо вебаппа (папка уже существует, 2 примера там
  лежат для образца).
- Имя файла: `<короткий_слаг>_<что-то узнаваемое>.jpg`, латиницей, без пробелов
  (по образцу `rufer_cat_spire.jpg`) — не обязательно жёстко формализовано, но
  должно быть понятно человеку, что на фото, при взгляде на список файлов.

## Как передать соответствие «файл → стиль»

Самое важное — это должно быть однозначно, иначе фронтенду придётся гадать.
Формат передачи (как в общем брифе): список строками `стиль → файл`, но
уточнение — «стиль» называть ТОЧНО как в `prompt_library.json`:
- Если у стиля есть `title` (в основном видео-стили и категория «Бьюти») —
  указывать title.
- Если title нет (большинство фото-стилей, это намеренно — см. AGENT_NOTES.md,
  не название стиля пусто просто так) — указывать связку «категория + начало
  description» (например: `С цветами → «Вечерний портрет с букетом белой
  сирени...»`), фронтенд сверит по совпадению и подставит.

Пример строки в списке:
```
Руферы → «Предложение с задержанием» → previews/rufer_proposal_v2.jpg
Портреты → «Пикник для контента...» → previews/portrait_picnic.jpg
```

## Что сделает фронтенд после получения материалов

Подставит `example_url: "previews/<файл>.jpg"` вместо текущих unsplash-ссылок
в соответствующих items `prompt_library.json`. Изменений в коде вебаппа не
требуется — только данные.

## Критерий готовности (для этого конкретного тикета)

Не обязательно все 20 сразу одним пакетом — можно передавать частями по мере
готовности, фронтенд подключит каждую партию отдельным маленьким PR.
