# ТЗ: Новый провайдер видео EvoLink — Gemini Omni, Kling Motion Control, перевод Seedance

Дата: 2026-07-31. Заказчик: Аня. Исполнитель: бэкенд. Статус: черновик на утверждение,
**заблокировано API-ключом EvoLink** (у Ани зарубежная карта, топ-ап будет).

Контекст: разведка конкурентов/провайдеров (маркетолог, 2026-07-31, Notion — «Сырник
— Маркетинг» → разведка @neiro_rusbot + сравнение цен). Текущий провайдер Zveno не
держит Gemini Omni и Kling Motion Control вообще; заодно сравнили цены на модели,
которые Zveno держит — по нескольким EvoLink оказался заметно дешевле.

## Решение владельца

- Добавить Gemini Omni и Kling Motion Control через EvoLink — новые продукты,
  без риска для существующих (Zveno их не предлагает, миграции нет).
- **Seedance (2.0 и 2.0-fast) тоже перевести на EvoLink** — экономика того стоит
  (см. таблицу ниже), но это МИГРАЦИЯ существующего рабочего продукта, поэтому
  делать через провайдер-флаг с быстрым откатом, не хардкодом.

## Цены (ориентир, сверить по факту после первых реальных счетов EvoLink)

| Модель | Zveno (сейчас, ₽/сек) | EvoLink (ориентир, ₽/сек по курсу ~90₽/$) | Экономия |
|---|---|---|---|
| Seedance 2.0 (обычный) | 11,38 | ≈5,13 | ~55% |
| Seedance 2.0-fast | ~9,1 (оценка, пропорция от cost_per_second в config) | ≈5,13 (EvoLink не разделяет fast-тариф явно — уточнить у поддержки) | требует проверки |
| Gemini Omni | — (нет у Zveno) | ≈7,8 | новый продукт |
| Kling Motion Control 2.6 | — (нет у Zveno) | Standard ≈5,4 / Pro ≈8,5 | новый продукт |

⚠️ Цены EvoLink взяты с их публичных страниц (websearch/webfetch 2026-07-31), не из
реального биллинга — до подтверждения первым счётом считать ориентировочными.
⚠️ Название модели не гарантирует идентичное качество/версию у разных провайдеров
(например Zveno отдельно не публикует «fast»-тариф Seedance с тем же названием,
что в нашем конфиге) — обязательна визуальная сверка на тестовых генерациях.

## Архитектура: провайдер-флаг, не хардкод

Не заменять вызовы Zveno на EvoLink напрямую в коде. Добавить:

- `config.py`: `EVOLINK_API_BASE`, `EVOLINK_API_KEY`, и per-модели флаг провайдера,
  например `SEEDANCE_PROVIDER = os.getenv("SEEDANCE_PROVIDER", "zveno")` (значения
  `"zveno"` / `"evolink"`). Аналогично для будущих моделей, если понадобится.
- В коде (`run_seedance`/аналог) — ветвление по `SEEDANCE_PROVIDER` на клиента Zveno
  или клиента EvoLink, единая точка логирования в `generation_events`
  (`provider="EVOLINK"` вместо `"ZVENO"`, остальные поля — по той же схеме, включая
  `error_type`/`error_message` для `/video_errors`).
- Код клиента Zveno НЕ удалять — держим минимум месяц как путь отката (флаг обратно
  в `"zveno"`, без редеплоя логики, только env-переменная).

## Kling Motion Control — доделать существующую заготовку

`start_kling_motion_control` (SirNike.py:7862) уже дёргает эндпоинт
`kling-2-6-motion-control`, но через `MASHAGPT_API_BASE`/`MASHAGPT_API_KEY` — сверить
формат запроса EvoLink (может отличаться от MashaGPT) и решить: переиспользовать
эту функцию с новым base/key, или завести отдельный клиент.

Критично — фича физически недостижима из интерфейса сейчас:
- `MOTION_CONTROL_ENABLED = 0` по умолчанию (config.py:102) — включить после теста.
- `waiting_for_motion_video` нигде не выставляется в коде — вход в UI (кнопка «Видео
  с движением», частично начата SirNike.py:3151) нужно довести: юзер загружает
  референс-видео с движением + своё фото → `start_kling_motion_control`.
- См. память `kling-api-not-connected` (может быть устаревшей на момент чтения —
  перепроверить состояние кода).

## Gemini Omni — новый провайдер с нуля

Свой блок в `config.py` (эндпоинт, ключ, длительности 3–10 сек по докам EvoLink),
обработчик по образцу `run_seedance`/`start_kling_motion_control`, цена в
изюминках с маржой ~x3.3 как у остальных видео-моделей, кнопка в `video_kb()`.

## Порядок работ (не всё сразу)

1. **Блокер**: Аня заводит аккаунт EvoLink, привязывает карту, минимальный топ-ап,
   выдаёт API-ключ.
2. Бэкенд делает тестовые генерации на EvoLink (Gemini Omni, Kling Motion Control,
   Seedance 2.0/fast) на тех же фото, что уже есть в проде через Zveno — сравнение
   бок о бок отправить Ане/маркетологу на ревью качества. **Не продолжать без ок.**
3. Если качество устраивает — имплементация по разделам выше, `SEEDANCE_PROVIDER`
   по умолчанию остаётся `"zveno"` до явного решения переключить.
4. Переключение Seedance на EvoLink в проде — только после недели наблюдения через
   `/video_errors` и `/pnl` за success rate новых моделей (Gemini Omni/Motion
   Control), чтобы не поймать те же проблемы, что были с seedance2_fast (28.6% SR,
   найдено 2026-07-21).
5. Цена для юзера в изюминках **не меняется** — экономия идёт в маржу, не в скидку
   (если Аня не решит иначе явно).

## Критерий готовности

- Gemini Omni и Kling Motion Control доступны в панели «Видео для Reels», прошли
  ревью качества.
- Kling Motion Control достижим из UI (не мёртвый код).
- Seedance переключён на EvoLink ТОЛЬКО после теста — `SEEDANCE_PROVIDER=evolink`
  в проде, success rate по `/video_errors` не хуже прежнего на Zveno, реальная цена
  по счёту EvoLink подтверждает экономию из таблицы (±20%).
- Путь отката на Zveno работает без изменения кода (одна env-переменная).
